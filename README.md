# Dr. Logan Kopp Website

Static site focused on driving specialty exotic companion mammal clients to Priest Lake Veterinary Hospital in Nashville.

## Structure
- `index.html` — Main page
- `styles.css` — Styles
- `images/` — Clinic and animal photos
- `blog/` — Blog posts (easy to add new HTML files)

## Hosting: Cloudflare Pages (Free)
1. In Cloudflare dashboard → Workers & Pages → Create → Pages → Upload assets.
2. Upload the contents of this folder.
3. Add custom domains (`logankopp.com` and/or `kopp.vet`).
4. SSL and DNS handled automatically.

## Blog Workflow
New posts are simple HTML files in the `blog/` folder. Link them from the main page’s blog section. A bot can draft posts, then you review and add them.
